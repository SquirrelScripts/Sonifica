# Sonifica

A simple musical playground app for toddlers — a companion to Colorifica.

## MVP goals

- Big, colorful tap targets
- Gentle synthesized sounds
- Three sound palettes (Bells, Drums, Animals)
- No ads, no accounts, no reading required

## Run locally

Just open `index.html` in a modern browser.
